Vigencia de la rifa

Despliegue del backend (una sola vez)

  1. Crea un Google Spreadsheet vacío (será el documento principal de todas las rifas).
  2. En script.google.com, crea un proyecto Apps Script y pega el contenido de assets/gas-rifa-Código.js.txt en Código.js.
  3. Propiedades del script: SPREADSHEET_ID (ID de la URL del Sheet) y MASTER_ADMIN_PIN (llave que tú eliges).
  4. Implementar → Aplicación web → Ejecutar como tú → acceso Cualquiera. Copia la URL /exec.
  5. En index.html asigna esa URL a window.CPM_RIFA_GAS_URL.

Uso diario

  • Guarda la Llave Maestra en la barra superior.
  • Usa + Nuevo para crear una rifa (se crea una hoja 00–99 y un link #r/…).
  • Comparte el link administrador con quien gestiona la rifa (no requiere login del sitio). La primera vez que lo abra, un asistente le guía paso a paso.
  • El instructivo para quien organiza está en Rifas Digitales.

Archivado automático

  • Al crear la rifa eliges cuándo se archiva. Al terminar ese día el link deja de funcionar.
  • En Lista → Archivadas puedes reactivarla con otra fecha o sin fecha, o eliminarla para siempre.
  • Ejecuta una vez instalarArchivadoAutomatico en el editor de Apps Script para que la hoja también se actualice sola cada noche.

Documentación detallada: docs/rifa-implementacion.md
